# Frontend — Codebase Assistant

Next.js web application for the Codebase Assistant tool.

## Pages

- / — Login and signup
- /dashboard — Index new repos, view and manage existing ones
- /chat — Chat with an indexed codebase using natural language
- /guide — View auto-generated onboarding guide for a repo
- /graph — Interactive dependency graph visualization

## Setup

See the root README.md for full setup instructions.

## Stack
- Next.js 16
- React
- Tailwind CSS
- Mermaid.js (diagram rendering)
- react-force-graph-2d (dependency graph)
